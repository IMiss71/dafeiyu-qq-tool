============================================================
  大肥鱼 QQ 部署向导 · 使用说明
============================================================

这是什么
  一个 Windows 一键部署向导：帮你装好 AstrBot + NapCat，
  配好模型，注入大肥鱼人设，启动 QQ 机器人。
  不需要管理员权限；不需要手改 JSON。

安装
  1. 双击 DaFeiYu-Setup-2.2.0.exe。
  2. 如果 Windows 弹“已保护你的电脑”，点：
       更多信息 → 仍要运行
     （免费项目没有购买代码签名证书，首次安装会出现一次，正常。）
  3. 安装过程只有一个进度页，不会弹 UAC，不会开黑色命令行窗口。
  4. 装完会自动打开向导页面（浏览器一个标签页）。

  不想安装？下载 Portable 版，解压到纯英文路径，
  双击 launcher\start-hidden.vbs 即可。

第一次使用
  跟着向导走：
    ① 环境检查
    ② 安装 AstrBot
    ③ 填模型（云端 Key 或本地 Ollama）
    ④ 注入人设
    ⑤ 登录 QQ（小号扫码）
    ⑥ 完成

  面板密码是每次安装随机生成的，在完成页 / “关于”页能看到；
  也保存在：
    %LOCALAPPDATA%\DaFeiYuQQ\dashboard_credentials.json

日常启动 / 停止
  启动：双击桌面“大肥鱼部署向导”，或开始菜单里的同名快捷方式。
        完全无窗口；已经在运行就只打开页面，不会重复启动。
  停止：开始菜单“停止大肥鱼”，或 launcher\stop-hidden.vbs。
  重启电脑后不会自动启动，需要手动点一次“启动”。

数据在哪
  程序：%LOCALAPPDATA%\Programs\DaFeiYuQQ
  数据：%LOCALAPPDATA%\DaFeiYuQQ
  卸载默认保留数据；要彻底清空，卸载后手动删除数据目录。

出问题
  先看向导里的“诊断”页，或双击 修复工具\ 下按现象命名的 .bat：
    01 初始化失败
    02 AstrBot 启动失败
    03 启动诊断
    04 不回消息诊断
    05 换号不回消息
  要发给人排查：向导首页“生成诊断报告”，Key/密码会自动打码。

注意
  - QQ 走非官方协议，有封号风险；务必用小号，不要用主号。
  - 不要把程序放在含中文/特殊字符的路径下。
  - 不要直接双击 wizard\index.html；那是本地文件，没有后端。
  - 本项目不上传 QQ 号、聊天记录、API Key 或任何文件内容。
  - 第三方组件许可见 LICENSE_NOTICE.md / OPEN_SOURCE_NOTICE.md。
