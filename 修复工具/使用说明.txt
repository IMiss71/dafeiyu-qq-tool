============================================================
  大肥鱼 · 修复工具使用说明
============================================================

这些工具只在“出问题”时用。装好之后的日常只需要：
  双击桌面的“大肥鱼部署向导”。

所有工具都只做修复/诊断，不动聊天记录；修完回向导继续即可。


------------------------------------------------------------
按现象选工具
------------------------------------------------------------

  现象：第②步一直“初始化失败” / 转圈
  用：01-初始化失败-修复.bat
  做什么：直接用已安装的 astrbot.exe 初始化，不联网重新下包；
          顺便把向导需要的端口（面板 16885 / OneBot 16199）写进配置。
  日志：桌面 AstrBot初始化修复.log

  现象：点“启动 AstrBot”失败 / 转圈 / 面板打不开
  用：02-AstrBot启动失败-修复.bat
  做什么：绕过向导里的 uvx，直接无窗口启动 AstrBot，
          并等面板端口就绪；关闭窗口不会杀掉已经起来的服务。
  日志：桌面 AstrBot手动启动.log

  现象：不知道哪里坏了，要先收集一份报告
  用：03-启动诊断.bat
  做什么：一次性收集系统信息、安装位置、配置文件、端口占用、
          日志尾部，最后给一句结论。
  日志：桌面 AstrBot诊断.txt（发给帮你的人之前先看一遍有没有隐私）

  现象：发消息没反应 / 对方收不到消息
  用：04-不回消息-诊断.bat
  做什么：检查三个端口、NapCat 有没有连回 AstrBot、
          AstrBot 有没有收到消息、适配器有没有连上。
  日志：桌面 五步不回消息诊断.txt（第 5 节直接给结论）

  现象：换了 QQ 号（大号换小号）之后不回消息
  用：05-换号不回消息-修复连接.bat
  做什么：NapCat 按 QQ 号分文件存配置；新号第一次登录需要
          重新写一份“连回 AstrBot”的 WebSocket 配置。
  注意：跑之前先关掉 NapCat（或向导里点“停止 NapCat”）。
  日志：桌面 小号换号修复.log


------------------------------------------------------------
排查顺序（不知道从哪开始就按这个）
------------------------------------------------------------

  1. 04-不回消息-诊断.bat  → 先看最后一段结论
  2. 按结论选：
       端口没起来            → 02 或直接一键启动
       没收到消息 / 没连上    → 05
       收到消息但没回复       → 模型 Key / 模型名（回向导第③步重测）
       AstrBot 装坏了         → 01，再不行回向导第②步“清空环境”重装
  3. 还是不行：把桌面的诊断 txt 发给帮你的人。


------------------------------------------------------------
常用地址
------------------------------------------------------------

  AstrBot 面板：http://127.0.0.1:16885/
    用户名：astrbot
    密码：每次安装随机生成，见向导完成页 / “关于”页，
          或 %LOCALAPPDATA%\DaFeiYuQQ\dashboard_credentials.json
    （装好后向导会自动登录，通常不用手输。）

  不回消息 90% 是这三条：
    - NapCat 没连上 AstrBot（反向 WS / 端口不对）  → 05
    - AstrBot 没启动                              → 02
    - 模型 Key / 模型名不对                        → 回向导第③步重测

  “一键启动”会常驻一个守护：AstrBot 掉了会自动拉起；
  但 QQ 被风控踢下线，只能人工扫码，任何工具都没法全自动。
