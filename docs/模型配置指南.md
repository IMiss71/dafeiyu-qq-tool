# 大肥鱼 · 模型配置完全指南

> 这份文档对应向导的**第 ③ 步「填写大模型」**。  
> 照着做，5 分钟能搞定；不想看长文，直接翻到最后的[三种推荐组合](#三种推荐组合抄作业版)。

---

## 0. 先搞懂一件事：大肥鱼「会聊天」靠的是别人家的 AI

大肥鱼自己不是模型，它只是个**传话的中间人**：

```
你的 QQ ──> NapCat ──> AstrBot（大肥鱼）──> 某个 AI 模型 ──> 组织成回复 ──> 你的 QQ
                                              ↑
                                    这里需要一个「模型」
```

这个「模型」有两种来路，向导都支持：

|       | 云端模型                    | 本地模型                |
| ----- | ----------------------- | ------------------- |
| 长什么样  | 一个网址 + 一串 `sk-` 开头的 Key | 在你电脑上跑一个几 GB 的模型文件  |
| 要钱吗   | 按用量付费，一般几十块够聊很久         | 完全免费                |
| 要配置吗  | 什么都不用装                  | 要装 Ollama、下模型（几 GB） |
| 速度    | 1~3 秒                   | 4~15 秒（看显卡/内存）      |
| 电脑会烫吗 | 不会（是别人家的服务器在算）          | 会，CPU/显卡会满载         |
| 断网能用吗 | ❌                       | ✅                   |
| 隐私    | 聊天内容会发到服务商              | 全在自己电脑里             |

**新手建议直接选云端。** 不用显卡、不用等下载、回复还快。

## 1. 路线 A：用云端模型（推荐）

### 1.1 硅基流动 SiliconFlow —— 最推荐，一把 Key 搞定所有事

为什么推荐它：**注册送额度**，而且**同一把 Key 既能聊天又能看图**，不用申请第二个账号。

**第 1 步：注册拿 Key**

1. 打开 <https://cloud.siliconflow.cn/i/dafeiyu>（或直接搜「硅基流动」）
2. 手机号注册 → 实名认证（国内服务商都要，1 分钟）
3. 左侧菜单「API 密钥」→「新建 API 密钥」
4. 复制那串 `sk-` 开头的字符串（**只显示一次**，先粘到记事本）

**第 2 步：在向导里填**

| 字段           | 填什么                                     |
| ------------ | --------------------------------------- |
| 服务商          | 硅基流动 SiliconFlow                        |
| API Key      | 刚才复制的 `sk-...`                          |
| API Base URL | 自动填好 `https://api.siliconflow.cn/v1`，别动 |
| 模型名          | 点「获取可用模型」，自动列出并选好                       |

**第 3 步：让它自己配好识图**

点「获取可用模型」后，向导会自动做三件事：

1. 列出这家所有模型（几十个），把 embedding、语音、画图的过滤掉
2. 主模型自动选 `deepseek-ai/DeepSeek-V3`
3. 识图模型自动选 `Qwen/Qwen2.5-VL-7B-Instruct`

你只需要点「写入配置并继续」。**什么都不用自己选。**

**它长什么样：**

```
服务商    [硅基流动 SiliconFlow        v]
API Key   [sk-你的Key                ]  ← 粘这里
Base URL  [https://api.siliconflow.cn/v1]  ← 自动
模型名    [deepseek-ai/DeepSeek-V3   ] [获取可用模型]
          ✓ 找到 87 个模型（可用聊天 41 个 / 能看图 6 个）
            已自动选择主模型 deepseek-ai/DeepSeek-V3；识图模型 Qwen/Qwen2.5-VL-7B-Instruct
```

---

### 1.2 DeepSeek —— 只聊天、不看图

**便宜，纯聊天很够用，但它家没有视觉模型**，大肥鱼会「看不见图片」。

1. 打开 <https://platform.deepseek.com/> → 注册 → 充值（10 块起）
2. 「API keys」→ 创建 → 复制
3. 向导里选「DeepSeek」，Key 粘进去，点「获取可用模型」

这时候向导会提示：`⚠️ 这家没有视觉模型，想看图的请改用硅基流动或阿里百炼。`

**如果你一定要用 DeepSeek 聊天 + 能看图**，两个办法：

- **办法一（推荐）**：主模型换硅基流动，一把 Key 全解决
- **办法二**：在「识图设置」里填硅基流动的信息，让聊天和识图走两家：

```
主模型：DeepSeek / deepseek-chat / 你的 DeepSeek Key

识图设置（展开）
  识图模型名   Qwen/Qwen2.5-VL-7B-Instruct
  识图 Base    https://api.siliconflow.cn/v1     ← 注意是硅基流动
  识图 Key     sk-你的硅基流动Key
```

向导允许主模型和识图模型用**不同服务商、不同 Key**，这是专门为这种混搭留的口子。

---

### 1.3 阿里百炼（通义千问）—— 有免费额度

1. 打开 <https://bailian.console.aliyun.com/> → 阿里云账号登录
2. 开通「百炼大模型服务」→ 实名
3. 「API-KEY 管理」→ 创建 → 复制
4. 向导里选「阿里百炼」，Key 粘进去，点「获取可用模型」

自动配好：主模型 `qwen-plus`，识图模型 `qwen-vl-max`。

> 阿里云新用户一般有 100 万 token 免费额度，够聊几千条。

---

### 1.4 OpenAI —— 质量高，但要能上外网

1. <https://platform.openai.com/api-keys> → 创建 Key
2. 向导里选「OpenAI」，填 Key

`gpt-4o` / `gpt-4.1` 系列**自己就能看图**，所以向导会自动勾上「这个模型能直接看图」，图片直接交给主模型，不需要额外的识图模型（这样看到的细节最全）。

⚠️ **必须先有代理**，否则会卡在「测试连接」超时。

---

### 1.5 中转站 / OneAPI / NewAPI

很多人用「中转站」（把多家 API 打包成一个地址，通常更便宜）。

1. 服务商选「自定义 / 中转站」
2. **Base URL** 填中转站给的地址，一般长这样：
   - `https://xxx.com/v1`
   - `https://api.xxx.com/v1`
   - 注意**结尾要有 `/v1`**，少了就是 404
3. **模型名**：点「获取可用模型」看它支持什么；不支持的话看中转站文档，照抄模型名
4. 如果这个模型本身能看图，勾上「这个模型能直接看图」

### 1.6 FreeLLMAPI —— 一分钱不花，把几十家免费额度捏成一个接口

[FreeLLMAPI](https://github.com/tashfeenahmed/freellmapi)（MIT 协议）是一个**跑在你自己电脑上**的网关：
你在各家平台注册免费账号，把 Key 填给它，它对外只给你一个 OpenAI 兼容地址，并在某家被限流（429）时自动换下一家。

**它适合谁**：想零成本试玩、有好几个平台免费额度、不追求 100% 稳定的人。
**它不适合谁**：把它当生产服务去卖钱（上游 ToS 不允许，且没有 SLA）。

**第一步：把它跑起来（一次性）**

1. 装 Node.js 20 或以上
2. 按它 README 的方式启动（默认监听 `http://127.0.0.1:3001`；也有 Docker 镜像）
3. 浏览器打开它的面板 → **Keys** 页，把各家的免费 Key 填进去（Google AI Studio / Groq / Cerebras / OpenRouter / 智谱 …）
4. 在 **Keys** 页顶部复制那把统一 Key，形如 `freellmapi-xxxxxxxx`

**第二步：在向导里填**

1. 服务商选 **FreeLLMAPI（本地聚合免费额度）**
2. API Key 粘上刚才复制的 `freellmapi-...`
3. API Base 默认就是 `http://127.0.0.1:3001/v1`，不用改
4. 模型名保持 `auto`（让它自己挑）；想偏快填 `auto:fast`，偏聪明填 `auto:smart`，也可以填它面板里的具体模型名
5. 点「测试连接」——成功就说明整条链路通了

**三个必须知道的坑**

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 测试连接失败 / 连接被拒绝 | FreeLLMAPI 没启动，或端口不是 3001 | 先把那个服务起起来；改了端口就同步改 API Base |
| 用着用着报 429 | 所有免费额度都到上限了 | 在它面板里加更多 Key、换 `auto:fast`，或留一个官方 Key 兜底 |
| 电脑重启后机器人不说话 | 本地服务没自启 | 把 FreeLLMAPI 设成开机自启，或换成硅基流动/DeepSeek |

> 大肥鱼插件里的「记忆提炼」「上下文压缩」也走这个模型，等于白嫖算力——但记得把插件里 `memory.extract_every` 调大一点，别把免费额度刷爆。

## 2. 路线 B：用本地模型（免费，但要你的电脑扛得住）

### 2.1 先装 Ollama

1. 打开 <https://ollama.com/download> → 下 Windows 版 → 双击装
2. 装完**它会在右下角托盘常驻**（一个羊驼图标），不用管它
3. 打开「命令提示符」（Win+R 输入 `cmd` 回车），敲：

```bat
ollama --version
```

能打印版本号就说明装好了。

> 装完 Ollama 记得**先别关电脑**，模型加载要它一直在跑。

### 2.2 下一个模型（关键：按你的配置选）

下载模型就是在命令行敲一句 `ollama pull 模型名`，等它下完（几 GB，看网速）。

**按你的电脑配置对号入座：**

| 你的配置              | 推荐模型                    | 大小      | 感受          |
| ----------------- | ----------------------- | ------- | ----------- |
| 8GB 内存，没独显        | `ollama pull qwen3:4b`  | 约 2.5GB | 能聊，反应慢，偶尔犯傻 |
| 16GB 内存，没独显       | `ollama pull qwen3:8b`  | 约 5GB   | 主力推荐，聊得动    |
| 16GB 内存 + 8GB 显存  | `ollama pull qwen3:8b`  | 约 5GB   | 很流畅，3~5 秒一条 |
| 32GB 内存 + 12GB 显存 | `ollama pull qwen3:14b` | 约 9GB   | 明显更聪明       |
| 24GB 显存以上         | `ollama pull qwen3:32b` | 约 20GB  | 接近云端水平      |

**想要「能看图」，要额外下一个视觉模型：**

| 配置            | 视觉模型                        |
| ------------- | --------------------------- |
| 8~16GB 内存     | `ollama pull qwen2.5vl:3b`  |
| 16GB 内存以上     | `ollama pull qwen2.5vl:7b`  |
| 32GB 以上 / 大显存 | `ollama pull qwen2.5vl:32b` |

> 亲测：`qwen3.5:4b` 这类模型名字里没有 `vl`，但其实带视觉能力，也能当识图模型用。  
> 向导的「获取可用模型」会一个个去问 Ollama 拿真实能力，**不靠猜名字**，所以这种模型会被正确标成「能看图」。

**下载完成后确认一下：**

```bat
ollama list
```

会列出你本机所有模型，形如：

```
NAME              ID              SIZE      MODIFIED
qwen3:8b          e4b0d639f9e5    5.2 GB    2 hours ago
qwen2.5vl:7b      2a7f1b3c8d4e    6.0 GB    10 minutes ago
```

### 2.3 在向导里填

| 字段       | 填什么                             |
| -------- | ------------------------------- |
| 服务商      | Ollama（本地免费）                    |
| API Key  | **留空**（本地不校验）                   |
| Base URL | 自动填 `http://localhost:11434/v1` |
| 模型名      | 点「获取可用模型」，从下拉里选你刚下的那个           |

点「获取可用模型」后，向导会：

1. 列出本机所有模型
2. 把 embedding 之类没用的过滤掉
3. 逐个问 Ollama「你能不能看图」，自动挑出视觉模型填进识图设置
4. 自动避开部署过程生成的临时变体（`-nothink`、`-cap` 这些）

### 2.4 本地模式的三个坑

**坑 1：回复是空的 / 机器人不回话**

`qwen3` 系列是「思考型」模型，它会先输出一大段内心独白，正文可能是空的。  
向导已经自动处理了（给主模型建一个关思考的 `-nothink` 变体），**你不用管**。

**坑 2：识别图片没反应**

多半是没装视觉模型，或者内存不够（视觉模型要额外 4~6GB）。  
打开「识图设置」看是不是空的；空的就 `ollama pull qwen2.5vl:7b` 再重新部署一次。

**坑 3：越聊越慢，最后卡死**

本地模型的上下文窗口有限（一般 8k）。聊久了历史太长会撑爆，表现为「一直转圈不出字」。  
向导已经把本地模式的上下文压到 15 轮；如果你还嫌慢，去 AstrBot 面板把 `max_context_length` 调到 10。

## 3. 向导里的三个按钮分别是干嘛的

| 按钮          | 作用                                   | 什么时候点                |
| ----------- | ------------------------------------ | -------------------- |
| **获取可用模型**  | 问服务商要模型列表，自动分类（聊天 / 看图 / 其他），自动选好推荐项 | 填完 Key 之后            |
| **测试连接**    | 真的发一次请求过去，验证 Key、模型名、地址对不对           | 写入前想确认一下             |
| **写入配置并继续** | 把配置写进 AstrBot                        | 前两个都 OK 之后（它会自己先测一遍） |

**智能在哪：**

- 你填错模型名（比如 `deepseek-v3` 其实叫 `deepseek-ai/DeepSeek-V3`），它会**自动换成正确的**并告诉你换成了什么
- 你选了纯文本模型，它会**自动挂一个识图模型**兜底，不让大肥鱼变成瞎子
- 你换服务商，它会**自动清掉上一次残留的识图配置**，不会一直去连一个已经关掉的本地服务
- 你填的模型本身能看图，它**自动勾上「能直接看图」**，省掉一次转写，图片细节不丢

## 4. 报错对照表（复制错误信息来这查）

| 屏幕上显示                   | 真实原因                        | 怎么修                                |
| ----------------------- | --------------------------- | ---------------------------------- |
| API Key 无效或已过期（401）     | Key 复制少了/多了空格/被删了           | 回服务商后台重新复制一整串，注意别漏掉 `sk-`          |
| 账户余额不足（402）             | 没钱了                         | 充值，或者换硅基流动（有免费额度）                  |
| 接口或模型不存在（404）           | ① 模型名拼错 ② Base URL 少了 `/v1` | 点「获取可用模型」让向导自己填；检查 URL 结尾是不是 `/v1` |
| 触发限流（429）               | 请求太快 / 免费额度用完了              | 等 1 分钟再试；或换个服务商                    |
| 请求超时                    | 境外服务没走代理                    | OpenAI 需要代理；国内的不会超时                |
| 连不上这个地址（ECONNREFUSED）   | 选 Ollama 但 Ollama 没启动       | 去开始菜单打开 Ollama，托盘出现羊驼图标再试          |
| 域名解析失败（ENOTFOUND）       | Base URL 拼错了 / 没网           | 检查 URL，特别是 `.com` `.cn` 有没有打错      |
| Ollama 在运行，但本机没有模型「xxx」 | 模型还没下载                      | 按提示 `ollama pull xxx`              |
| 这家没有视觉模型                | 服务商确实没有                     | 换硅基流动 / 阿里百炼，或用混搭办法（见 1.2）         |
| 机器人不回消息                 | ① 配置没生效 ② 上下文撑爆             | 重启 AstrBot；本地模式把上下文调到 10           |

## 5. 成本到底多少

按大肥鱼的人设（约 1200 字）+ 15~~30 轮上下文 + 每 2~~3 条回复一次表情包分类：

| 服务        | 每 1000 条消息 | 说明          |
| --------- | ---------- | ----------- |
| 硅基流动      | ¥1 ~ 3     | 注册送的额度够聊几千条 |
| DeepSeek  | ¥1 ~ 2     | 最便宜         |
| 阿里百炼      | ¥1 ~ 3     | 新用户有免费额度    |
| OpenAI    | ¥10 ~ 30   | 贵，但质量最好     |
| 本地 Ollama | ¥0         | 只花电费        |

**语音不花钱**：用的是微软 Edge 的免费 TTS 服务，跟模型无关。

**识图大概**：每次 ¥0.001 ~ 0.01（看图片大小）。

> 省钱的土办法：把 `generation.emotion.probability` 从 40 调到 20，  
> 表情包判定请求少一半；或者干脆设 0 关掉。

## 三种推荐组合（抄作业版）

### 🥇 组合一：省心型（90% 的人选这个）

```
服务商：硅基流动
Key：注册送的
主模型：deepseek-ai/DeepSeek-V3（自动选）
识图：Qwen/Qwen2.5-VL-7B-Instruct（自动选）
花费：几十块能用很久
配置时间：3 分钟
```

### 🥈 组合二：零花钱型

```
聊天：DeepSeek / deepseek-chat
识图：不开（大肥鱼会说"我看不到图"）
花费：最便宜
配置时间：2 分钟
```

### 🥉 组合三：完全免费 + 隐私型

```
服务商：Ollama
先跑：ollama pull qwen3:8b
再跑：ollama pull qwen2.5vl:7b
花费：0 元
配置时间：20 分钟（大头是下模型）
要求：16GB 内存以上，最好是独显
```

## 附：换模型之后要做什么

**必须重启 AstrBot**，配置才会生效：

1. 关掉那个写着 `AstrBot` 的黑窗口
2. 回向导点「启动 AstrBot」
3. 或者直接在 AstrBot 面板右上角点重启

配置本身存在 `%LOCALAPPDATA%\DaFeiYuQQ\data\cmd_config.json`，想手动改也可以，但**改完一定要重启**。
