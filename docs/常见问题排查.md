## 一、双击 bat 没反应 / 一闪而过

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 双击完全没反应 | 杀毒软件拦截 | 把工具目录加白名单；看向导首页「环境体检」的杀软检测项 |
| 窗口一闪就关 | 找不到 Node | 去装 Node.js 18+，或把 `node.exe` 放进 `tools\node.exe` |
| 提示"未知发布者" | 未做代码签名 | 正常现象，点「仍要运行」 |
| 弹出乱码窗口（满屏"不是内部或外部命令"） | bat 被记事本等软件转存成 UTF-8 | 新版启动脚本已改为纯英文提示、任何情况不会再乱码：重新解压**最新分发包**覆盖即可（不用重装，数据不受影响）。旧包用户找卖家要「启动修复包」 |

## 二、向导页面打不开 / 白屏

1. **页面完全打不开**：等 bat 窗口出现"向导已启动"再刷新；确认浏览器地址是 `http://127.0.0.1:18765/`（端口可能顺延，看 bat 窗口提示或 `wizard.port` 文件）。
2. **白屏**：必须是**整站代理的入口**（向导里的按钮），不能直接双击 `wizard/index.html`（file:// 没有后端，全部按钮失效）。
3. **一直转圈**：后端可能已被杀软结束，重新双击 bat。

## 三、安装 AstrBot / 下载 NapCat 失败

| 提示 | 解决 |
| --- | --- |
| PyPI 安装失败 / 超时 | 检查网络与代理；公司/校园网可能屏蔽镜像，换手机热点试试 |
| 下载停滞超时 | 向导已自动重试 + 多源竞速，点「重试」再来一次；反复失败多半是网络/代理问题 |
| 校验失败（大小/魔数） | 下载源被劫持或文件不完整，向导会自动换源重下 |
| 磁盘不足 | AstrBot + Python 约 2GB，先清理出 3GB 以上空间 |
| 路径报错 | 工具目录放到**纯英文路径**（如 `D:\dafeiyu`），中文路径会导致多种诡异失败 |


## 三之二、卡在「初始化失败」

向导第②步进度停在「正在初始化数据目录…」，然后报「初始化失败」或一直转圈。旧版这里是 `uvx astrbot init`，
uvx 会另建缓存把 AstrBot 重新下载一遍，客户网络慢就会超时。新版已改为直接用本机装好的 `astrbot.exe`，一般几秒过。

| 现象 | 解决 |
| --- | --- |
| 仍然报初始化失败 | 关掉向导，双击 **`修复工具/01-初始化失败-修复.bat`**（用已装 exe 初始化，并补 dashboard 16885 / aiocqhttp 16199 端口），跑完回向导再点一次 |
| 提示「没找到 astrbot.exe」 | AstrBot 没装成功：回第②步右上角「清空环境」→ 重装 |
| 提示「astrbot.exe 运行失败」 | 装坏了（常见于安装中断网）：同样清空环境重装 |
| 修复脚本也失败 | 看桌面 `AstrBot初始化修复.log`；同时确认 C 盘 >3GB、杀软没拦 `%LOCALAPPDATA%\DaFeiYuQQ` |


## 三之三、点「启动 AstrBot」失败 / 一直转圈

旧版向导用 `uvx astrbot run` 启动，uvx 会先解析/校验自己的环境，客户机上可能卡几十秒甚至超时，向导等不到面板（16885）就报「启动失败」。
AstrBot 本身没坏 —— 直接调 `astrbot.exe run` 通常 4~5 秒就能起来。v1.1.2 起已改为直接启动 exe。

| 现象 | 解决 |
| --- | --- |
| 旧包里点启动失败 | 双击 **`修复工具/02-AstrBot启动失败-修复.bat`**，看到「启动成功」后回向导点「启动 NapCat」 |
| 想彻底修好 | 换 v1.1.2 及以上分发包（向导已直接用 astrbot.exe 启动） |
| 提示「数据库未生成」 | 先跑 `修复工具/01-初始化失败-修复.bat`，再启动 |
| 启动工具也失败 | 桌面 `AstrBot手动启动.log` 有 stdout/stderr；再跑 `启动诊断.bat` 抓完整现场 |


## 三之四、机器人不回消息 / 换了 QQ 号不回

按顺序做，**先双击 `一键启动大肥鱼.vbs`**（它会自动补配置并重连，多数情况一步解决）：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 换了小号后不回 | NapCat 按 QQ 号分文件存配置，新号那份里面没有「连回 AstrBot」的 WebSocket | 双击 `一键启动大肥鱼.vbs`；不行再跑 `修复工具/05-换号不回消息-修复连接.bat`（跑前先关 NapCat） |
| 一直不回、日志没有新行 | NapCat 没连上 / 没登录 | `修复工具/04-不回消息-诊断.bat`，看第 5 节结论 |
| 有收到消息但没回复 | 模型 Key / 模型名 / 额度 | 回向导第③步点「测试连通」 |
| 重启电脑后不回 | 服务没启动（不会开机自启） | 双击 `一键启动大肥鱼.vbs` |
| 想彻底关掉 | — | `一键停止大肥鱼.vbs`（QQ 自带守护会把 NapCat 拉起来，属正常；AstrBot 停了就不会回消息） |

> 面板：`http://127.0.0.1:16885/`，用户名 `astrbot`，密码见向导完成页 / `dashboard_credentials.json`（每次安装随机生成）。

## 四、NapCat 扫码后连不上 / 机器人不回消息

按顺序自查（这是最常见的问题链）：

1. **NapCat 登录的是哪个号？** 向导用的是小号。扫码后确认 NapCat 面板左上角是登录成功的状态。
2. **AstrBot 起了吗？** 向导第 ⑤ 步点「启动」，等状态变绿。
3. **WS 连接上了吗？** 向导状态里找「aiocqhttp(OneBot v11) 适配器已连接」。没连上就重启 AstrBot——向导有自动自愈，最多等 2 分钟。
4. **⚠️ 最隐蔽的一种：配置都对，WS 就是没连上**（全新安装最容易踩）。
   NapCat 只在**启动/登录那一刻**读配置；扫码登录后向导才补写的 WS 配置，它不会热加载。
   特征：NapCat 正常收消息、配置文件里 `websocketClients` 也是 `enable:true`，但机器人死活不回。
   **解决：把 NapCat 重启一次**（向导里再点一次「启动 NapCat」，或结束 NapCat 进程后重开）。
   新版向导会在这种状态持续 3 分钟后自动帮你重启，无需手动处理。
5. **模型 Key 填了吗？** Key 为空时 AstrBot 收到消息也无法回复。去第 ③ 步填好并「写入配置」。
6. **怎么发消息？** 私聊小号，或在群里 @ 小号。群里没反应先试私聊。
7. **还是不回**：重启大法——先停 AstrBot 再启动，再不行把 NapCat 面板退出重登。

## 四之二、桌面上弹出十几个 QQ 窗口 / 登的是大号切不了 / 机器人掉线

**① 弹出一堆 QQ 黑窗口**

原因：反复点了「启动」，旧版每次点击都会多开一个 QQ（新版已修复）。

| 步骤 | 操作 |
| --- | --- |
| 1 | 双击「一键停止大肥鱼.vbs」全部停掉 |
| 2 | 任务管理器（Ctrl+Shift+Esc）→ 结束所有还在的 **QQ.exe** 和 **NapCatWinBootMain.exe** |
| 3 | 重新解压最新分发包覆盖（拿到防重复启动的新版），再点**一次**「启动」 |
| 4 | 以后看到机器人在跑就不要再点启动，每点一次多开一个 QQ |

**② 登录的是自己的大号，切不成小号**

原因：你电脑上的 QQ 自己记住了「自动登录大号」，不是工具配的。

1. 在已登录大号的 QQ 面板：左下角点头像 →「退出登录」
2. 设置里如有「自动登录」开关，**先关掉**
3. 回到登录窗口，用小号扫码登录（勾上「自动登录」）
4. 回向导点一次「启动」，机器人就连上小号了

**③ 机器人突然不回消息了（掉线）**

| 情况 | 表现 | 怎么办 |
| --- | --- | --- |
| NapCat/QQ 崩溃 | 向导状态变红 | 不用管，向导会自动拉起（15 秒内） |
| 小号被腾讯踢下线 | NapCat 面板显示未登录 | 打开 NapCat 面板（向导页有入口）重新扫码；向导最多自动重试 3 次，之后需要人工扫码 |
| 风控要求验证 | 扫码后提示异常 | 用小号手机 QQ 完成一次安全验证再扫 |
| 电脑重启了 | 全部没起 | 双击「一键启动大肥鱼.vbs」 |

> 长期挂机建议：用专门的小号、关闭该号的「自动登录」以外的多设备登录、别在大号上挂机器人。

## 五、机器人回话报错 / 内容为空

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 回复"401 / 认证失败" | Key 错或被删 | 重新粘贴 Key，注意别带空格 |
| 回复"404 / model not found" | 模型名打错 | 用「获取可用模型」点选，别手打 |
| 回复"余额不足" | 服务商欠费 | 去服务商后台充值 |
| **收到消息但完全不回** | 思考型模型（如 Qwen3）正文为空 | 向导会自动处理：云端自动关思考、本地自动建 `-nothink` 变体；若是手改过配置，重新用向导写入 |
| 发图后报 400 | 纯文本模型不吃图片 | 用向导的「识图设置」配一个视觉模型（推荐 `Qwen/Qwen2.5-VL-7B-Instruct`） |
| 回复特别慢 | 本地模型太小/太热，或云端限速 | 换小一点的量化模型，或换服务商 |

## 六、语音 / 识图 / 表情包不生效

先明确：**本向导默认不预装表情包、识图等插件**，这些能力由 AstrBot 插件生态提供，去 AstrBot 面板 → 插件市场按需安装；装好后一般要重启 AstrBot 才生效。

- **语音（TTS）**：内置能力，走免费的 Edge TTS，装完就能用。注意换模型后要**重启 AstrBot**。
- **识图**：装识图类插件（如 reimage）后，在向导第 ③ 步「识图设置」里配视觉模型；本地 Ollama 需要拉一个视觉模型（如 `qwen2.5vl`）。
- **表情包**：装表情包插件后按概率触发，不是每条都发；触发频率在插件自己的配置里调。

## 七、端口被占用

- 向导体检会列出被占端口和占用进程，点 **「释放端口」** 一键处理。
- 向导端口 18765 被占会自动顺延到 18766~18775，实际端口看 bat 窗口提示。
- 手动查占用：`netstat -ano | findstr :16885`，再看 PID 对应的进程名。

| 问题 | 解决 |

| 换模型后没生效 | 重启 AstrBot（停掉再启动），配置才重新加载 |
| 忘了 AstrBot 面板密码 | 去 `%LOCALAPPDATA%\DaFeiYuQQ\dashboard_credentials.json` 看；向导「关于」页也会显示 |
