# 部署完成后：一键启动 / 关闭大肥鱼

首次用部署向导完成 AstrBot + NapCat 配置，并确认 QQ 能收发消息后，日常不需要再打开向导。

## 桌面快捷方式

安装 2.4.0 后会出现：

| 快捷方式 | 作用 |
|---|---|
| **启动大肥鱼** | 一键启动 AstrBot + NapCat，无黑窗，先隐藏运行 |
| **停止大肥鱼** | 一键停止 AstrBot + NapCat（同时停向导） |
| **停止大肥鱼（仅机器人）** | 只停机器人，不影响正在看的向导 |
| **大肥鱼部署向导** | 改配置、扫码、看 Doctor 时才打开 |

## 对应脚本

```text
{app}\一键启动大肥鱼.vbs
{app}\一键停止大肥鱼.vbs
{app}\launcher\stop-hidden.vbs   # 连向导一起停
```

启动脚本会：

1. 启动 AstrBot（面板 16885）
2. 启动 NapCat（WebUI 6099 / 反向 WS 16199）
3. 显示 QQ 登录二维码（如果未登录）
4. 后台运行，不保留黑窗口

停止脚本会停止上述进程，**不会删除聊天数据、记忆、表情包和配置**。

## 日常流程

```text
开机
  → 双击「启动大肥鱼」
  → 等 QQ 登录
  → 正常收发消息

不用了
  → 双击「停止大肥鱼」
```

如果换了 QQ / 改了模型 Key / 端口：

```text
双击「大肥鱼部署向导」→ 改配置 → 保存 → 重新启动
```

## 注意

- 开机不会自动启动，需要手动双击「启动大肥鱼」。
- 「启动大肥鱼」只启动机器人，不打开向导。
- 停止后数据不会丢；下次启动继续用。
- 如果启动失败，打开向导 → Doctor 诊断，或看 `%LOCALAPPDATA%\DaFeiYuQQ\boot.log`。
