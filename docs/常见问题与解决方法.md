# 大肥鱼常见问题与解决方法

文档版本：2.4.0 / 插件 1.9.0  
文档性质：官方故障排查手册

---

## 1. 排查原则

故障处理应遵循以下顺序：

1. 确认故障现象与发生时间。
2. 检查 AstrBot、NapCat、插件三层状态。
3. 查看日志与 Doctor 报告。
4. 优先修改配置，不得直接删除用户数据。
5. 涉及数据目录操作前，先完成备份。

标准排查顺序：

| 顺序 | 检查项 |
|---:|---|
| 1 | NapCat 是否在线 |
| 2 | AstrBot 是否运行 |
| 3 | 插件是否启用 |
| 4 | 模型 Key 是否有效 |
| 5 | 是否处于勿打扰时段 |
| 6 | 是否触发群聊/频率限制 |
| 7 | 查看日志与 Doctor 报告 |

---

## 2. 安装程序被 SmartScreen 拦截

**现象**：提示“Windows 已保护你的电脑”或“未知发布者”。

**原因**：安装程序未进行代码签名。

**处理方法**：

1. 核对安装包来源与 SHA256。
2. 选择“更多信息”。
3. 选择“仍要运行”。
4. 右键安装程序，选择“以管理员身份运行”。

如仍被拦截，可临时关闭 Windows 安全中心的 SmartScreen，安装完成后重新开启。

---

## 3. 安装程序无法启动或提示权限不足

**原因**：安装程序需要写入程序目录、快捷方式和运行环境。

**处理方法**：

1. 使用管理员权限运行安装程序。
2. 避免在压缩包内直接运行，应先解压。
3. 将安装路径改为纯英文路径，例如 `D:\DaFeiYuQQ`。
4. 检查杀毒软件是否拦截安装程序，必要时将安装目录加入信任列表。

---

## 4. 向导页面无法打开

**现象**：浏览器空白、连接被拒绝或页面无法加载。

**处理方法**：

1. 关闭旧的向导进程后重新启动。
2. 检查端口占用：

```powershell
netstat -ano | findstr :16885
netstat -ano | findstr :6099
netstat -ano | findstr :16199
```

3. 结束占用端口的进程，或重启计算机。
4. 确认未同时启动多个部署向导。
5. 不得直接双击 `wizard/index.html`。

---

## 5. NapCat 扫码失败或持续离线

**处理方法**：

1. 确认 QQ 小号可在手机 QQ 正常登录。
2. 清除 NapCat 旧登录缓存后重新扫码。
3. 检查 QQ 是否触发安全验证或风控。
4. 核对 NapCat 与 AstrBot 的端口配置。
5. 扫码完成后等待 10-20 秒，避免连续刷新。

---

## 6. AstrBot 面板无法访问

**处理方法**：

1. 确认 AstrBot 已启动。
2. 使用 `http://127.0.0.1:16885`，不得使用 HTTPS。
3. 检查 16885 端口是否被占用。
4. 查看 `%LOCALAPPDATA%\DaFeiYuQQ\logs` 中的错误。
5. 使用“停止大肥鱼”后重新“启动大肥鱼”。

---

## 7. 插件上传失败或插件列表不显示

**原因**：zip 结构错误、manifest 校验失败、AstrBot 版本过低，或已安装同名插件。

**处理方法**：

1. 使用交付包中的原始插件 zip，不得自行重新压缩。
2. 三档插件只能安装一个。
3. 确认 AstrBot 版本不低于 4.25.0。
4. 上传完成后重启 AstrBot。
5. 查看 AstrBot 日志中的 manifest 或 SHA256 错误。
6. 如已安装同名插件，先卸载旧版本，再安装新版本。

---

## 8. 机器人不回复

**处理方法**：

1. 确认 NapCat 在线。
2. 确认 AstrBot 面板可访问。
3. 确认插件已启用。
4. 检查 API Key、API Base、模型名和余额。
5. 检查是否处于勿打扰时段。
6. 检查群聊接话概率、日限额和频率限制。
7. 检查 QQ 是否被禁言或风控。
8. 查看 AstrBot 日志与 `doctor.json`。

---

## 9. 模型返回 401 / 403 / 余额不足

| 状态 | 常见原因 |
|---|---|
| 401 | Key 错误、过期或复制不完整 |
| 403 | Key 无权限、模型未开通或地区限制 |
| 余额不足 | 模型账户余额不足 |

**处理方法**：

1. 在模型服务商后台确认 Key 状态。
2. 核对 API Base 是否为 OpenAI 兼容地址。
3. 核对模型名称。
4. 不得在群聊、截图或文档中公开 Key。

---

## 10. 回复过长、过短或客服腔

**原因**：人设提示词、风格配置或插件参数不一致。

**处理方法**：

1. 检查 AstrBot 人设是否为 `dafeiyu`。
2. 检查人设字数、语气和禁止事项。
3. 检查插件面板中的风格注入与防复读设置。
4. 修改后重启 AstrBot。

---

## 11. 表情包不发送

**处理方法**：

1. 检查 `meme_packs` 目录是否存在图片。
2. 在插件面板确认分类和关键词。
3. 检查表情功能开关。
4. 检查发送概率是否设置为 0。
5. 图片格式建议为 jpg、png 或 webp，文件名避免特殊符号。

---

## 12. 语音或唱歌无声音

**处理方法**：

1. 检查语音功能是否开启。
2. 检查 Edge TTS 是否可用。
3. 唱歌功能需要 GPT-SoVITS；未配置时仅使用普通音色。
4. 检查系统音频输出设备。
5. 查看 AstrBot 日志中的 TTS 错误。

---

## 13. 识图或梗图理解不工作

**处理方法**：

1. 检查视觉模型 Key 与 API Base。
2. 检查“识图”开关。
3. 图片过大时先压缩。
4. 梗图理解为进阶版/全能版能力，基础版不包含。
5. 查看日志中的视觉 API 错误。

---

## 14. 记忆不生效或记错

**处理方法**：

1. 确认插件为进阶版或全能版。
2. 在面板查看记忆列表。
3. 使用“记住/忘掉”命令修正。
4. 记忆提炼存在间隔，不会对每条消息立即写入。
5. 避免频繁清空记忆。

---

## 15. 掉线后消息未补发

**说明**：

- 插件仅补发已生成但未发送成功的回复。
- 机器人完全离线期间，AstrBot/NapCat 不会保存并回放对方消息。
- 重新上线后，新消息正常处理。

**处理方法**：

1. 检查断线补发开关。
2. 检查 outbox / pending 数量。
3. 确认 NapCat 重连成功。
4. 重要消息由人工补回。

---

## 16. 桌面快捷方式缺失

**处理方法**：

1. 重新运行安装程序并选择修复。
2. 检查开始菜单中的“大肥鱼”目录。
3. 手动运行安装目录下的：
   - `一键启动大肥鱼.vbs`
   - `一键停止大肥鱼.vbs`
4. 检查杀毒软件是否拦截快捷方式创建。

---

## 17. 卸载后数据仍存在

**说明**：卸载程序默认保留用户数据，便于重装恢复。

彻底清理步骤：

1. 备份需要保留的内容。
2. 执行卸载。
3. 手动删除 `%LOCALAPPDATA%\DaFeiYuQQ`。
4. 删除桌面和开始菜单快捷方式。

---

## 18. 抖音桥相关问题

抖音桥为独立项目，不包含在本交付包中。

常见问题：

- 登录失效：停止桥 → 运行 `登录.cmd` 扫码 → 重新启动。
- 找不到私信面板：抖音页面改版，需要更新桥代码。
- 出现安全验证或滑块：桥会停机，不得自动绕过验证码。
- 账号封禁风险：抖音桥违反平台用户协议，必须使用小号。
- `edge-profile` 包含登录态，不得对外分发。

---

## 19. 故障信息收集

提交故障报告时，应提供：

1. 部署工具版本：2.4.0
2. 插件版本：1.9.0
3. Windows 版本
4. AstrBot 日志最后 100 行
5. NapCat 状态
6. 插件 `doctor.json`
7. 故障发生时间与操作步骤

## 20. 管理命令提示无权限

**现象**：发送 `/大肥鱼`、`/dafeiyu`、`/dfy_doctor` 后没有状态或提示无权限。

**原因**：1.8.1 起管理命令仅对 AstrBot 管理员开放。

**处理方法**：

1. 打开 AstrBot 面板 → 访问控制 / 管理员。
2. 将使用者 QQ 号加入 `admins_id`。
3. 保存并重启 AstrBot。
4. 确认命令由管理员账号发送。

该限制用于避免普通群成员查看插件状态、功能清单、记忆、联系人、说说内容，或执行清空记忆、发说说、主动私聊等管理操作。

不得提供：

- API Key
- QQ 密码
- `data_v4.db`
- `edge-profile`
- 完整聊天记录
