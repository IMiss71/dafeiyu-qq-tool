# 大肥鱼 · 使用说明

> 3 步上手：**双击启动 → 填 Key → 扫码**。详细图文见 [模型配置指南.md](模型配置指南.md)，出问题先翻 [常见问题排查.md](常见问题排查.md)。

## 第 1 步：启动

双击工具目录里的 **`start-wizard.bat`**（或 `启动向导.bat`，两者相同）。
浏览器会自动打开 `http://127.0.0.1:18765/`，向导页面自动做一次环境体检，按提示处理标红项即可。

## 第 2 步：填模型 Key

向导第 ③ 步选服务商（推荐**硅基流动**，注册送额度），粘贴 API Key → 点「获取可用模型」选一个 → 点「写入配置」。
写入前会自动做一次真实请求自检，Key/模型名填错会当场告诉你原因。

不想花钱？选 **本地 Ollama** 跑免费模型（需要显卡，见模型配置指南）。

## 第 3 步：小号扫码登录

向导里点「安装 NapCat」→ 打开 NapCat 面板 → 用**不重要的 QQ 小号**扫码登录。
登录后向导会自动把 QQ 通道接到 AstrBot，看到「aiocqhttp(OneBot v11) 适配器已连接」就成功了。

之后在 QQ 上私聊小号、或在群里 @ 它，大肥鱼就会回话。

## 日常使用

| 想做什么 | 怎么做 |
| --- | --- |
| 启动 | 双击 `start-wizard.bat` |
| 停止 | 关掉向导后，在任务管理器结束 `python` / `node` 相关进程，或重启电脑 |
| 改人设 | 向导「人设」步骤一键注入，或去 AstrBot 面板（`http://127.0.0.1:18666/`，账号 `astrbot` / `DaFeiYu666`）改 |
| 换模型 | 向导第 ③ 步重填 → 重启 AstrBot 生效 |

## ⚠️ 注意

- QQ 走的是**非官方协议**，有封号风险 → 务必用小号，不要用主号。
- Windows 弹 SmartScreen 提示点「仍要运行」即可（脚本未做付费签名）。
- 不要把工具目录放在含中文/特殊字符的路径下。
- 排障求助时，用向导里的「生成诊断报告」，Key/密码会自动打码，发给帮你的人即可。
