# 大肥鱼 · 使用说明

> 3 步上手：**双击启动 → 填 Key → 扫码**。详细图文见 [模型配置指南.md](模型配置指南.md)，出问题先翻 [常见问题排查.md](常见问题排查.md)。

## 第 1 步：启动

双击桌面/开始菜单的 **「大肥鱼部署向导」** 快捷方式；便携版双击 `launcher\start-hidden.vbs`。
（不要双击 `wizard/index.html`，那是本地文件，没有后端。）
浏览器会自动打开 `http://127.0.0.1:18765/`，向导页面自动做一次环境体检，按提示处理标红项即可。

## 第 2 步：填模型 Key

向导第 ③ 步选服务商（推荐**硅基流动**，注册送额度），粘贴 API Key → 点「获取可用模型」选一个 → 点「写入配置」。
写入前会自动做一次真实请求自检，Key/模型名填错会当场告诉你原因。

不想花钱？选 **本地 Ollama** 跑免费模型（需要显卡，见模型配置指南）。

## 第 3 步：小号扫码登录

向导里点「安装 NapCat」（包内已带官方离线包，直接解压，几秒完成，不用等下载）→ 打开 NapCat 面板 → 用**不重要的 QQ 小号**扫码登录。
登录后向导会自动把 QQ 通道接到 AstrBot，看到「aiocqhttp(OneBot v11) 适配器已连接」就成功了。

之后在 QQ 上私聊小号、或在群里 @ 它，大肥鱼就会回话。

## 日常使用

装好之后，**每天只需要双击 `一键启动大肥鱼.vbs`**：完全无窗口，自动起好 AstrBot + NapCat，
并常驻一个守护（AstrBot 掉线自动拉起 / NapCat 崩溃自动重启 / 换号后自动补 OneBot 配置）。
关闭用 `一键停止大肥鱼.vbs`。想看启动过程用 `一键启动（看进度）.bat`。
只有改配置、换模型的时候才需要再打开向导。

| 想做什么 | 怎么做 |
| --- | --- |
| 启动 | 双击桌面/开始菜单「大肥鱼部署向导」；便携版用 `launcher\start-hidden.vbs` |
| 停止 | 开始菜单「停止大肥鱼」，或 `launcher\stop-hidden.vbs`（聊天数据不会丢；电脑重启后机器人不会自启，属正常） |
| 改人设 | 向导「人设」步骤一键注入，或去 AstrBot 面板（`http://127.0.0.1:18666/`，账号 `astrbot`，密码见向导完成页 / `dashboard_credentials.json`）改 |
| 换模型 | 向导第 ③ 步重填 → 重启 AstrBot 生效 |

## ⚠️ 注意

- QQ 走的是**非官方协议**，有封号风险 → 务必用小号，不要用主号。
- Windows 弹 SmartScreen 提示点「仍要运行」即可（脚本未做付费签名）。
- 不要把工具目录放在含中文/特殊字符的路径下。
- 卡在「初始化失败」：关掉向导，双击 **`修复工具/01-初始化失败-修复.bat`**，跑完回向导再点一次「安装并初始化」。
- 排障求助时，用向导里的「生成诊断报告」，Key/密码会自动打码，发给帮你的人即可。
