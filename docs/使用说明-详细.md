# 大肥鱼部署工具使用说明

文档版本：2.4.0 / 插件 1.11.0  
适用系统：Windows 10 / 11 x64  
文档性质：官方安装、配置与运维说明

---

## 1. 文档说明

本文档用于说明大肥鱼 QQ AI 部署工具（以下简称“本工具”）的安装、初始化、插件部署、日常运行、数据维护与卸载流程。

本工具负责 AstrBot、NapCat、模型配置、人设注入、插件包管理和启动诊断；QQ 机器人插件由独立插件包提供，本工具不内置插件源码。

适用人员：

- 首次部署大肥鱼 QQ 机器人的安装人员
- 需要修改模型、人设、插件配置的运维人员
- 需要排查安装或运行故障的技术支持人员

---

| 项目 | 要求 |

| 内存 | 4GB 及以上；本地 Ollama 建议 16GB |

安装路径建议使用纯英文且不含空格的目录，例如 `D:\DaFeiYuQQ`。

## 4. 安装前检查

安装前应确认：

1. 系统为 Windows 10/11 x64。
2. 已准备可用的 QQ 小号，不建议使用主号。
3. 已准备模型 API Key，或本机 Ollama 服务。
4. `16885`、`6099`、`16199` 端口未被其他程序占用。
5. 安装包来源可信，且 SHA256 校验一致。

校验方式：

```powershell
Get-FileHash .\DaFeiYu-Setup-2.4.0.exe -Algorithm SHA256
```

计算结果应与 `SHA256SUMS.txt` 中对应记录一致。

## 5. 安装部署工具

### 5.1 安装版

1. 右键 `DaFeiYu-Setup-2.4.0.exe`，选择“以管理员身份运行”。
2. 如出现“Windows 已保护你的电脑”或“未知发布者”提示，原因为安装程序未进行代码签名。
3. 确认文件来源可信后，选择“更多信息” → “仍要运行”。
4. 按安装向导选择安装目录。
5. 安装完成后，桌面与开始菜单将生成以下入口：
   - 启动大肥鱼
   - 停止大肥鱼
   - 大肥鱼部署向导

### 5.2 便携版

1. 解压 `DaFeiYu-Portable-2.4.0.zip` 至纯英文路径。
2. 运行 `launcher\start-hidden.vbs` 或开始菜单入口。
3. 不得直接双击 `wizard/index.html`；该方式缺少本地后端，功能不可用。

### 5.3 安装位置

| 类型 | 路径 |
|---|---|
| 程序目录 | `%LOCALAPPDATA%\Programs\DaFeiYuQQ` |
| 运行数据 | `%LOCALAPPDATA%\DaFeiYuQQ` |
| AstrBot 数据 | `%LOCALAPPDATA%\DaFeiYuQQ\data` |

卸载程序默认保留运行数据，便于重装后恢复。

## 6. 初始化配置

### 6.1 打开部署向导

安装完成后启动“大肥鱼部署向导”，浏览器将打开本机回环地址页面。向导仅监听 `127.0.0.1`，不开放局域网访问。

安装人员应按向导顺序完成以下步骤，不建议跳步。

### 6.2 配置模型

模型配置项如下：

| 项目 | 示例 |
|---|---|
| 类型 | OpenAI 兼容 |
| 名称 | deepseek |
| API Base | `https://api.deepseek.com/v1` |
| 模型 | `deepseek-flash` 或 `deepseek-chat` |
| API Key | 用户自己的 Key |

配置要求：

1. 使用用户本人或所属组织合法持有的 API Key。
2. 不得使用来源不明的共享 Key。
3. 模型服务应兼容 OpenAI `/chat/completions` 接口。
4. 配置完成后应执行连通性测试，测试通过后再进入下一步。

### 6.3 安装 AstrBot 与 NapCat

1. 在向导中选择安装 AstrBot。
2. 等待 Python 环境与依赖安装完成。
3. 安装 NapCat。
4. 启动 NapCat，按提示完成 QQ 扫码登录。
5. 确认 NapCat 状态为在线。
6. 返回向导，启动 AstrBot。
7. 打开 AstrBot 面板，默认地址为 `http://127.0.0.1:16885`。

面板凭据保存在 `%LOCALAPPDATA%\DaFeiYuQQ\dashboard_credentials.json`，不得写入日志或对外公开。

## 7. 部署插件

### 7.1 选择插件版本

| 版本 | 能力数量 | 适用范围 |
|---|---:|---|
| 基础版 | 4 | 随机延迟、表情包、断线补发、工具、面板 |
| 进阶版 | 9 | 基础版 + 主动私聊、空间说说、长期记忆、压缩、梗图理解 |
| 全能版 | 14 | 全部能力，含群聊上下文、语音、识图、唱歌、ASR |

三档插件共用同一内部插件名，单台设备只能安装一个版本。

### 7.2 上传流程

1. 打开 AstrBot 面板。
2. 进入“插件”页面。
3. 选择“安装插件”，上传对应版本的 zip。
4. 启用插件。
5. 如插件未立即显示，重启 AstrBot。
6. 打开插件页中的“大肥鱼面板”，确认面板可正常加载。

升级或降级插件时，应保留 `data/`、记忆、联系人、表情分类等用户数据。

### 7.3 表情包数据

插件包不包含表情图片。图片应放置于：

```text
%LOCALAPPDATA%\DaFeiYuQQ\data\plugins\astrbot_plugin_dafeiyu\meme_packs\
```

分类的新增、重命名和删除应在插件面板“表情包”页面完成。

## 8. 启动与停止

### 8.1 桌面快捷方式

| 快捷方式 | 功能 |
|---|---|
| 启动大肥鱼 | 启动 AstrBot 与 NapCat，无窗口 |
| 停止大肥鱼 | 停止 AstrBot 与 NapCat |
| 停止大肥鱼（仅机器人） | 仅停止机器人，不关闭向导 |
| 大肥鱼部署向导 | 修改配置、扫码、运行 Doctor |

### 8.2 启动后检查

1. NapCat 在线。
2. AstrBot 面板可访问。
3. 插件状态为已启用。
4. 向机器人发送测试消息，确认可正常回复。

## 9. 人设与勿打扰

### 9.1 人设

QQ 人设保存在 AstrBot 数据库 `personas` 表，`persona_id` 为 `dafeiyu`。部署工具默认人设位于 `assets/dafeiyu_persona.txt`。

修改人设后应重启 AstrBot，确保新提示词生效。

### 9.2 管理命令权限

`/大肥鱼`、`/dafeiyu`、`/dfy_doctor` 属于管理命令，仅 AstrBot 管理员可用。

配置方式：

1. 打开 AstrBot 面板。
2. 进入“访问控制 / 管理员”。
3. 将使用者的 QQ 号加入 `admins_id`。
4. 保存后重启 AstrBot。

未配置管理员的账号执行上述命令时不会返回插件状态、功能清单、记忆、联系人或说说内容。

### 9.3 勿打扰

勿打扰设置位于插件面板“拟人/聊天”配置。默认时段为 `00:00-08:00`。

勿打扰期间：

- 私聊不回复
- 群聊不接话
- 主动消息暂停
- 提醒暂停
- 空间说说暂停

时段结束后自动恢复，不补发勿打扰期间收到的消息。

## 10. 数据、备份与迁移

### 10.1 必须保留的数据

```text
%LOCALAPPDATA%\DaFeiYuQQ\data
```

主要数据：

| 文件/目录 | 内容 |
|---|---|
| `data_v4.db` | AstrBot 会话、人设 |
| `plugins\astrbot_plugin_dafeiyu\data\memory.json` | 长期记忆 |
| `...\social.json` | 联系人、待跟进、主动社交状态 |
| `...\meme_index.json` | 表情索引 |
| `...\reminders.json` | 提醒 |
| `plugin_backups\` | 插件升级备份 |

### 10.2 备份

停止大肥鱼后，复制整个 `%LOCALAPPDATA%\DaFeiYuQQ\data` 目录至备份介质。

### 10.3 迁移

1. 在目标设备安装同版本部署工具。
2. 停止大肥鱼。
3. 将备份的 `data` 目录覆盖至目标设备对应路径。
4. 启动大肥鱼并检查插件、模型、QQ 登录状态。

## 11. 升级与卸载

### 11.1 升级

1. 下载新版本安装包或插件包。
2. 停止大肥鱼。
3. 安装新版本部署工具，或上传新插件 zip。
4. 保留用户数据，不执行清空操作。
5. 启动并验证。

### 11.2 卸载

1. 停止大肥鱼。
2. 打开 Windows“设置” → “应用” → “大肥鱼 QQ 部署向导”。
3. 执行卸载。
4. 卸载程序默认保留 `%LOCALAPPDATA%\DaFeiYuQQ`。
5. 确认不再使用后，可手动删除该数据目录。

## 12. 日志与诊断

| 位置 | 用途 |
|---|---|
| AstrBot 面板 → 日志 | 插件、模型、消息处理日志 |
| `%LOCALAPPDATA%\DaFeiYuQQ\logs` | AstrBot / NapCat 运行日志 |
| `...\data\plugins\astrbot_plugin_dafeiyu\data\doctor.json` | 插件自检结果 |
| 向导首页 | 安装步骤、失败原因、修复入口 |

故障排查顺序：

1. NapCat 是否在线
2. AstrBot 是否运行
3. 插件是否启用
4. API Key 是否有效
5. 是否处于勿打扰时段
6. 查看日志与 Doctor 报告

## 13. 安全要求

1. 安装程序未签名，仅应从可信来源获取。
2. 不得将 `%LOCALAPPDATA%\DaFeiYuQQ` 目录对外分发；其中包含账号、聊天记录和人设数据。
3. 不得在截图、日志、文档或群聊中暴露 API Key。
4. 不得安装来源不明的插件包。
5. 抖音桥为独立项目，不包含在本交付包中；其涉及平台风控与个人登录态，不建议分发。
6. 公开大规模分发前，建议完成代码签名与发布校验。
